由标准的 [ROS 2 客户端支持库 (rcl)](https://github.com/ros2/rcl/) 和新的 [ROS 2 客户端库包 (rclc)](https://github.com/ros2/rclc/) 组成的 micro-ROS 客户端库将包含所有主要的 ROS 概念，例如：

* 节点
* 发布者/订阅者
* 服务/客户端
* 图形
* 执行器
* 生命周期
* 参数

Humble 版本中已提供大多数功能。请参阅我们的[功能概述页面](/docs/overview/features/) 了解详细状态。要了解如何使用 rcl + rclc 开发您自己的应用节点，请参阅相应的[编程教程](/docs/tutorials/programming_rcl_rclc/)。
