将 micro-ROS 功能与 ROS 2 功能进行对比。以下列表编译自 [https://docs.ros.org/en/rolling/The-ROS2-Project/Features.html](https://docs.ros.org/en/rolling/The-ROS2-Project/Features.html) 和 [https://docs.ros.org/en/rolling/The-ROS2-Project/Roadmap.html](https://docs.ros.org/en/rolling/The-ROS2-Project/Roadmap.html)，并根据 [功能和架构页面](https://micro-ros.github.io//docs/overview/features/) 中定义的宏类别将功能组织成子表。

### 支持所有主要 ROS 概念的微控制器优化客户端 API

| ROS 2 功能                                                            |                                                  | micro-ROS 中的可用性                                                                                                                                                                                                                                                                                                                                                                                        |
| ------------------------------------------------------------------------- | ------------------------------------------------ | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 由语言特定库包装的通用核心客户端库 | <span class="status_flag">&#10003;&#8728;</span> | 按原样使用 ROS 2 的客户端支持库 [rcl](https://github.com/ros2/rcl/)。 [rclc](https://github.com/ros2/rclc) 包提供了便捷函数和执行器，将 rcl+rclc 用作 C 编程语言的客户端库。 *路线图：将所有功能迁移到 rclc，使其成为 rcl 之上的独立抽象层，作为用户的 API。* |
| 在编译、链接或 dlopen 时组合节点组件 | <span class="status_flag">&#10003;</span>        | 仅支持编译时组合。运行时的组合高度依赖于 RTOS。                                                                                                                                                                                                                                                                                                                        |
| 支持具有生命周期管理的节点                                 | <span class="status_flag">&#10003;</span>        | [rclc_lifecycle](https://github.com/ros2/rclc/blob/master/rclc_lifecycle/) 包提供了一种 `rclc_lifecycle_node` 类型，它将 rcl 节点与生命周期状态机以及相应的便捷函数捆绑在一起。                                                                                                                                                                         |
| 静态和动态处理类型和主题内存的工具 | <span class="status_flag">&#10003;</span>        | [micro_ros_utilities](https://github.com/micro-ROS/micro_ros_utilities) 提供了使用 micro-ROS 分配器或静态内存池处理类型内存的 API。                                                                                                                                                                                                                                         |

### 与 ROS 2 无缝集成

| ROS 2 功能                                                  |                                                  | micro-ROS 中的可用性                                                                                                                                                                                                                                                                          |
| -------------------------------------------------------------- | ------------------------------------------------ | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 主题上的发布/订阅                                  | <span class="status_flag">&#10003;</span>        | 可用，但仅支持固定大小的消息类型以避免动态内存分配。                                                                                                                                                                                                        |
| 客户端和服务                                           | <span class="status_flag">&#10003;</span>        | 可用，但仅支持固定大小的消息类型以避免动态内存分配。                                                                                                                                                                                                        |
| ROS 1 -- ROS 2 通信桥                            | <span class="status_flag">&#10003;</span>        | 标准 ROS 1 -- ROS 2 桥或 SOSS 调解桥可通过 micro-ROS 代理与 micro-ROS 节点通信。                                                                        |
| 动作                                                        | <span class="status_flag">&#10003;</span>        | 在 RCLC 级别可用。                                                                                                                                                                                                                                                                           |
| 参数                                                     | <span class="status_flag">&#10003;&#8728;</span> | 参数服务器在 micro-ROS 客户端中实现。参数客户端尚不可用。                                                                                                                                                                                                        |
| 节点图                                                     | <span class="status_flag">&#10003;</span>        | 与 ROS 2 中一样可用。                                                                                                                                                                                                                                                                             |
| 发现                                                      | <span class="status_flag">&#10003;&#43;</span>   | 实体之间的发现与 ROS 2 中可用。客户端还提供了进一步发现机制，用于在网络上发现代理。                                                                                                                                                         |
| 使用相同 API 的进程内和进程间通信      | <span class="status_flag">&#10003;&#8728;</span> | MCU 上的共享内存进程间通信在 micro-ROS 客户端中可用。中间件也可以实现线程安全操作。                                                                                                                                                     |
| 使用可扩展框架的命令行内省工具 | <span class="status_flag">&#10003;</span>        | 借助图支持，标准 ROS 2 工具可用于通过代理从运行 micro-ROS 节点的微处理器内省 ROS 2 数据空间的拓扑。同时，标准 ROS 2 节点可以获取网络上存在的 micro-ROS 实体的信息。 |
| 用于协调多个节点的启动系统                  | <span class="status_flag">&#8331;</span>         | MCU 上没有适用于 micro-ROS 节点的启动系统。此类系统高度依赖于 RTOS。与 micro-ROS 一起开发的系统模式概念允许运行时配置/协调 ROS 2 和 micro-ROS 节点。                                                   |
| 节点和主题的命名空间支持                         | <span class="status_flag">&#10003;</span>        | 与 ROS 2 中一样可用。                                                                                                                                                                                                                                                                             |
| ROS 名称的静态重映射                                  | <span class="status_flag">&#8727;</span>         | *如果通过标准 rcl API 作为参数传递，应该可用——有待检查。*                                                                                                                                                                                                                 |
| 使用系统时钟的速率和睡眠支持                    | <span class="status_flag">&#8727;</span>         | rcl 定时器使用 POSIX API。在 NuttX 上测试成功，但分辨率非常低。可以通过硬件定时器实现更高分辨率——这高度依赖于 MCU 和可能的 RTOS。 *此功能需要进一步研究。*                                        |
| 仿真时间支持                                        | <span class="status_flag">&#8727;</span>         | *可能开箱即用，但需要检查。* 我们认为带仿真时间的 HIL 设置是边缘情况。                                                                                                                                                                      |

### 超资源受限但灵活的中间件

| ROS 2 功能                                               |                                                | micro-ROS 中的可用性                                                                                                                                                                                                                                                                                                                              |
| ----------------------------------------------------------- | ---------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| DDS-XRCE 和 DDS 上的传输和序列化 | <span class="status_flag">&#10003;&#43;</span> | 可用传输：UDP、串行 (UART) 和由 [Micro XRCE-DDS](https://github.com/eProsima/Micro-XRCE-DDS) 启用的自定义传输。客户端与代理之间的序列化由 [Micro-CDR](https://github.com/eProsima/Micro-CDR) 提供，代理与标准 DDS 之间由 [Fast-CDR](https://github.com/eprosima/Fast-CDR) 提供。                |
| 运行时选择的多个 DDS 实现支持 | <span class="status_flag">&#10003;</span>      | 原则上可以通过 Micro XRCE-DDS 代理支持，但仅在编译时。                                                                                                                                                                                                                                                               |
| 处理非理想网络的服务质量设置 | <span class="status_flag">&#10003;&#43;</span> | 对于 DDS-XRCE 有线协议上的通信，提供了两种 QoS 语义，可靠和尽力而为，可在编译时设置。至于与 ROS 2 数据空间的通信，micro-ROS 实体可以在创建时受益于 DDS 允许的完整 QoS 集 [通过引用](/docs/tutorials/advanced/create_dds_entities_by_ref/)。 |
| DDS-安全支持                                        | <span class="status_flag">&#10003;&#45;</span> | 客户端与代理之间的通信过程尚不支持安全。然而，micro-ROS 代理可以在创建 DDS 实体时受益于 Fast DDS 安全功能。 *路线图：计划在未来版本中实现 Micro XRCE-DDS 的安全机制。*                                     |
| IDL                                                         | <span class="status_flag">&#10003;&#43;</span> | micro-ROS 支持与 ROS 2 相同的 IDL 类型。从 IDL 生成 C 代码由客户端使用 [Micro-XRCE-DDS-Gen](https://github.com/eProsima/Micro-XRCE-DDS-Gen) 库处理，而代理处理的 C++ 类型生成由 [Fast-DDS-Gen](https://github.com/eProsima/Fast-DDS-Gen) 处理。             |
| 日志                                                     | <span class="status_flag">&#8727;</span>       | *原则上可以作为标准日志机制的一部分可用，但由于动态消息大小，Micro-XRCE-DDS 不支持。有待检查...*                                                                                                                                                                                         |

### 具有通用构建系统的多 RTOS 支持

| 功能                     |                                           | micro-ROS 中的可用性                                                                                                                                                                                                                                                                                                                                                                                           |
| --------------------------- | ----------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 构建系统                | <span class="status_flag">&#10003;</span> | micro-ROS 提供了两种构建 micro-ROS 应用程序的方式。第一种使用集成在 ROS 2 工作空间中的 [micro_ros_setup](https://github.com/micro-ROS/micro_ros_setup) 工具。使用这种方法，NuttX、FreeRTOS 和 Zephyr 的构建系统与 colcon 集成。另一种将 micro-ROS 作为外部开发框架（例如 ESP-IDF 和 Zephyr 构建系统）的组件提供。 |
| 支持的硬件          | <span class="status_flag">&#10003;</span> | micro-ROS 官方支持四款开发板。目前，所有官方端口均基于 ST 的 STM32 系列和 Espressif 的 ESP32。在[此处](https://micro-ros.github.io/docs/overview/hardware/)了解更多详情。用户还完成了更多端口，请查看[完整列表](https://github.com/micro-ROS/micro_ros_setup#supported-platforms)。                                            |
| 支持的操作系统 | <span class="status_flag">&#10003;</span> | 除 Linux 和 Windows 外，micro-ROS 还支持 FreeRTOS、Zephyr、NuttX 等 RTOS。                                                                                                                                                                                                                                                                                                                     |

### micro-ROS 特定功能

| 功能                                   |                                                  | micro-ROS 中的可用性                                                                                                                                                                                                                                                                                                                                                                                                                                          |
| ----------------------------------------- | ------------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| 全 ROS 2 移动机器人演示        | <span class="status_flag">&#10003;</span>        | 提供多个 ROS 2 + micro-ROS 机器人演示。请参阅 [https://micro-ros.github.io/docs/tutorials/demos/](https://micro-ros.github.io/docs/tutorials/demos/)。                                                                                                                                                                                                                                                                                                   |
| 实时代码支持                | <span class="status_flag">&#10003;</span>        | 实时行为是 micro-ROS 典型用例的关键。[rclc 执行器](https://github.com/ros2/rclc/tree/master/rclc) 提供了实现实时关键应用的机制。在较低层级，Micro XRCE-DDS 库表现出实时性和确定性，因为它是免动态内存的，并提供在明确定义的时间段内执行任务的函数。                                                                |
| "裸机"微控制器支持 | <span class="status_flag">&#10003;</span>        | 将 ROS 2 带到 MCU 上正是 micro-ROS 的全部内容。micro-ROS 的标准方法假定底层有 RTOS（例如 [FreeRTOS](https://www.freertos.org/)、[Zephyr](https://www.zephyrproject.org/) 或 [NuttX](http://nuttx.apache.org/)）。最近的开发旨在放宽这一要求，集成到 [Arduino IDE](https://github.com/micro-ROS/micro_ros_arduino) 是迈向真正 micro-ROS 裸机支持的第一步。 |
